## Deployment

This site is deployed as a **static site on DigitalOcean App Platform**.

Every push to the `main` branch triggers an automatic deployment.

```bash
# Make your changes, then:
git add .
git commit -m "your message"
git push
# Live in ~2 minutes
```

---

## Local Development

No build step needed. Just open `index.html` in your browser, or use the VS Code Live Server extension for hot reload.

```bash
# Clone the repo
git clone https://github.com/SreenivasBR/sreenivas-raman.git
cd sreenivas-raman

# Open in VS Code
code .
```
